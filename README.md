# dbm-swmm
Coupling the Discrete Boltzmann Model with the Storm Water Management Model for Urban Pluvial Flood Simulation

The DBM was originally developed by Meng Jianping et al., and is available at [https://github.com/inmeso/mplb](https://github.com/inmeso/mplb).
